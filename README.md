# FuraFila Digital 🥪🥤

Sistema de gestão de cantina escolar para otimização de filas e controle de estoque.

## Status do Projeto: Em Desenvolvimento 🚧

A branch **`main`** contém a versão estável e final do sistema. Atualmente, encontra-se apenas com o commit inicial, pois o código está em constante evolução na branch de desenvolvimento.

O projeto só receberá merges nesta branch quando a aplicação estiver concluída e pronta para produção/entrega.

## Acesso ao Projeto 
Para acompanhar o andamento atual, acesse a branch `develop`.
